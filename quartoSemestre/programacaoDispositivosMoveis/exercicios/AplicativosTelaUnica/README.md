# Aplicativos de Tela Única

Projeto Android em Kotlin para a atividade de **Programação para Dispositivos Móveis**.

## Funcionalidades

1. Quatro operações fundamentais: soma, subtração, multiplicação e divisão.
2. Conversão de Celsius para Fahrenheit (`F = C × 9/5 + 32`).
3. Cálculo pela primeira Lei de Ohm (`V = R × I`): informe exatamente dois valores para encontrar o terceiro. Caso haja menos ou mais de dois campos preenchidos, o app mostra um Toast.

## Como abrir

Abra a pasta deste projeto no Android Studio e aguarde a sincronização do Gradle. Em seguida, execute em um emulador ou celular com Android 7.0 (API 24) ou superior.
